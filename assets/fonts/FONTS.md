# Fonts

- **SpaceMono-Regular.ttf** - Space Mono, bundled with the original Expo template (OFL).
- **SpaceGrotesk-Bold.ttf** - Space Grotesk by Florian Karsten, SIL Open Font License 1.1
  (see OFL-SpaceGrotesk.txt). Source: github.com/google/fonts, ofl/spacegrotesk.
  Vendored as a static 700-weight instance produced from the upstream variable font,
  because React Native / expo-font does not reliably select variable-font weights.
